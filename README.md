# Lié Larousse · sito personale

Sito della scrittrice Lié Larousse. Sezioni: Bio, Libri, Blog (con il canale YouTube *Libroarbitrio · Il tempo di un tè con Lié*), Contatti.

- `index.html` – contenuti
- `style.css` – stile acquerello botanico (carta antica, rame, salvia, papavero, lavanda)
- `img/` – fotografie

Per pubblicarlo gratis: Settings → Pages → Branch `main` / root.

## Traduzioni
Le versioni inglese (`en/`) e francese (`fr/`) si generano dalle pagine italiane con
`python3 _strumenti/traduci.py`. Dopo ogni modifica ai testi italiani, aggiornare i
dizionari nello script e rilanciarlo.
